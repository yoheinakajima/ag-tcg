# Git Hygiene Plan (Pass 7A, Part H)

**Scope of this pass:** add `.gitignore` rules so newly-generated heavy/ephemeral
artifacts stay out of the repo going forward. **No history rewriting and no
`git rm` is performed in this pass** — untracking already-committed files is a
deliberate, separate step listed under "Deferred cleanup" below so it can be
reviewed before anything is removed.

## Why

Some lab artifacts are large and fully reproducible, so committing them only
bloats the repo:

- `experiments/runs*/**/smoke_result.html` — per-game render dumps, **8-17 MB
  each**, regenerable from a replay. These dominate repo size.
- `data/activegraph/ptcg_ledger_events.jsonl`, `ptcg_ledger_runs.json`,
  `data/activegraph/artifacts/` — the durable run ledger (Pass 7A). This is the
  local source of truth for run/candidate/game state, but it is *regenerated* per
  run and must never be uploaded; it does not belong in version control.
- `data/site/` — the generated HTML report (projection of the ledger).
- `data/experiments/run_state/` — transient per-game run-state scratch.

## What this pass changed

Appended a clearly-labeled "Pass 7A" block to `.gitignore` covering the paths
above. Existing rules (Kaggle card data, submission tarballs, match artifacts)
are untouched.

Intentionally **kept tracked**:

- `data/experiments/cabt_import_benchmark.json` — small, meaningful deliverable
  recording the validated import speedup (Part F).
- All docs under `docs/`, the `src/ptcg_activegraph/ag/` package, the durable
  runner, and tests.

## Verifying a path is ignored

```bash
git check-ignore -v experiments/runs/<id>/smoke_result.html
git check-ignore -v data/activegraph/ptcg_ledger_events.jsonl
```

A printed rule means the path is ignored for *future* commits. Files already in
the index are unaffected until explicitly untracked.

## Currently-tracked generated artifacts (found via `git ls-files`)

A read-only audit found these already-committed, regenerable artifacts. They stay
tracked in this pass (no `git rm`); the new `.gitignore` only stops *new* ones.

- **`experiments/runs*/**/*.html` — 36 files, ~214 MB total.** By far the
  biggest win. Each is a per-game render dump reproducible from a replay.
- `data/site/*.html` + `style.css` — the generated report site (projection of the
  ledger; regenerate with `scripts/build_report_site.py`).
- `data/experiments/*.json` and `*.md` — rankings, fixture-gate and contract
  artifacts (regenerated by the ranking/report tooling).
- `data/activegraph/lab_events.jsonl` — legacy event stream (the new Pass 7A
  ledger writes `ptcg_ledger_events.jsonl`, already ignored).

**Worth preserving for the Strategy report narrative** (do NOT untrack): the
`branch.yaml` and `metrics.json` lineage files inside each run dir, and
`data/experiments/cabt_import_benchmark.json` (the validated import speedup).

## Warnings

- **Official card data / credentials must never be committed.** Existing rules
  already ignore `EN_Card_Data.csv`, `JP_Card_Data.csv`, `*Card_Data.csv`,
  `data/cards/*.pdf`, and Kaggle CLI logs (`data/kaggle_uploads/`). Do not weaken
  these. The durable ledger stores only run/game metadata — never card data.

## Deferred cleanup (NOT done here — requires explicit approval)

Already-committed heavy artifacts remain tracked until a future, reviewed pass.
When approved, untrack them **without deleting the working copies**:

```bash
# preview only
git ls-files 'experiments/runs*/**/smoke_result.html' | xargs du -ch | tail -1
# untrack (keeps files on disk), then commit
git rm --cached experiments/runs*/**/smoke_result.html
```

This is deferred on purpose: `git rm` is destructive to the index and should be
run as its own change with a clear diff, not bundled into Pass 7A. The immutable
baselines (`data/baselines/v1_kaggle_349_8/`, `v2_kaggle_479_1_*`) and the root
`main.py`/`deck.csv` must never be touched by any cleanup.
