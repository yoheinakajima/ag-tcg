- Avoid discarding the only visible Snover if no Snover is on board.

2. policy_ultra_ball_v2
Hypothesis:
Ultra Ball should discard excess Water Energy and search for the missing setup piece.

Rules:
- If no Basic attacker/bench support exists, prefer Kyogre or Snover.
- If Snover is on board and Mega Abomasnow ex is available, prefer Mega Abomasnow ex.
- If no Snover is on board, prefer Snover over Mega Abomasnow ex.
- Prefer not to search a duplicate low-value card.

3. policy_secret_box_v2
Hypothesis:
Secret Box is powerful but dangerous; use it only when there are safe discards and choose coherent targets.

Rules:
- Do not play Secret Box if hand has fewer than 3 safe discard cards unless no better action exists.
- Safe discards: excess Basic Water Energy first.
- Unsafe discards: only Snover, only Mega Abomasnow ex, only attacker, only search card.
- For ToHand choices, prefer coherent package:
  - Mega Signal only if Snover line is preserved or on board.
  - Powerglass if an attacker is active.
  - Lillie/Petrel if deck count is healthy.
  - Surfing Beach only if not already in play.

4. policy_mega_signal_v2
Hypothesis:
Mega Signal should not fetch Mega Abomasnow ex unless Snover exists or is likely usable.

Rules:
- If Snover is on board, prefer Mega Abomasnow ex.
- If Snover is not on board but Snover is available in options, prefer Snover if allowed.
- If no Snover exists, deprioritize Mega Abomasnow ex and choose the best alternative.

5. policy_deckout_guard_v1
Hypothesis:
The bot loses long games by over-drawing/searching into zero deck; avoid optional draw/search when deckCount is low.

Rules:
- If own deckCount <= 8, penalize draw/search/supporter/stadium abilities unless they immediately enable attack/evolution/KO.
- If own deckCount <= 4, heavily penalize optional draw/search effects.
- Never choose draw-count > 0 if deckCount is very low unless required.
- End/pass can be acceptable if the alternative is self-deckout.
