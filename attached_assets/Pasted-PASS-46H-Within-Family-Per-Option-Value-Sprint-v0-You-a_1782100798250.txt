Strategic context:
Pass 46G tested phase-aware and role-aware additive turn-planner profiles. The candidates were safe and non-inert, but no profile cleared the promising bar. The key finding was that phase/role layers are too coarse and mostly top-1 inert. The one interesting signal was diamond_phase going 8–2 vs parent, but that was not attributable to the phase/role layer; it looked more like family-weighted scorer transfer.

This pass should move one level lower: build within-family per-option value features that score the actual legal option, target, card, zone, and visible board context. Do not optimize one deck blindly; build reusable option-value infrastructure and test a small local batch.
