PART C — Mutation operators v0
Implement deterministic mutation operators for stdlib-safe candidates first.

Required operators:
1. basic_density_adjustment
   - Change Basic Pokémon count by small deltas where legal.
   - Preserve 60 cards.
   - Do not invent card IDs.
   - Only use card IDs already present in the source family or verified from existing legal deck families.
2. energy_ratio_adjustment
   - Adjust basic energy count up/down by small deltas.
   - Preserve legal 60-card deck.
   - Avoid over-dilution.
3. draw_search_ratio_adjustment
   - Swap small counts among already-used draw/search cards if legal.
   - No unknown IDs.
4. conservative_policy_weight_delta
   - For stdlib candidates only, adjust existing role/weight constants if the candidate's compiler supports it.
   - Must be non-inert in fixture or live trace.
5. no-op sentinel
   - Deliberately produce a no-op candidate and verify it is rejected as duplicate/inert. This is a regression test, not a pool entrant.

Do NOT implement family-specific mutation policies yet. That is a future pass.
Do NOT use LLM output to directly create candidates in v0.
