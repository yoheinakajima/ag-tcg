Use confirmed card IDs:

- 3 Basic {W} Energy

- 1092 Secret Box

Playbook should encode:

gameplan:
- primary: Kyogre pressure
- secondary: Snover → Mega Abomasnow setup
- avoid: self-deckout and orphan Mega Abomasnow line

roles:
- primary_attackers: Kyogre
- setup_basics: Snover
- evolution_payoffs: Mega Abomasnow ex
- search_cards: Ultra Ball, Mega Signal
- risky_search_cards: Secret Box
- draw_cards: Lillie's Determination, Team Rocket's Petrel, Surfing Beach
- tools: Powerglass
- energy: Basic Water

opening:
- active priority:
  - Kyogre when available with Water/search support
  - Snover when evolution support is strong
- bench priority:
  - Kyogre
  - Snover
  - avoid unnecessary benching if no payoff

discard safety:
- prefer discarding excess Basic Water Energy
- avoid discarding only Snover
- avoid discarding only Mega Abomasnow when Snover exists
- avoid discarding only attacker
- avoid discarding only search card if setup incomplete

Ultra Ball:
- discard excess Water first
- if no Snover on board/hand, search Snover over Mega Abomasnow
- if Snover exists, search Mega Abomasnow
- if no attacker exists, search Kyogre or Snover
- avoid low-value duplicate search

Secret Box:
- play safety is advisory, not hard-fixtured, because main option schema is not deterministic enough
- forced discard all is not failure
- ToHand package priority:
  - Powerglass if Kyogre active and no tool
  - Mega Signal only if Snover line exists or is preserved
  - Lillie/Petrel only when deck count is healthy
  - Surfing Beach only if not already in play
  - avoid redundant stadium

Mega Signal:
- if Snover exists active/bench/hand, prefer Mega Abomasnow
- if no Snover line exists, avoid orphan Mega Abomasnow if decline/alternative exists

deckout guard:
- deckCount <= 8: penalize optional draw/search
- deckCount <= 4: heavily penalize optional draw/search
- deckCount <= 2: prefer attack/attach/end over draw/search unless immediate win/survival

attachment:
- attach Water to active Kyogre if attacking plan
- attach tool Powerglass to active Kyogre if no tool
- otherwise attach to next attacker
- avoid attaching to low-value target when better target exists

fixture requirements:
- must pass all hard Pass 8 fixtures
- Secret Box forced_all is NA, not fail
- ToHand role priority should improve advisory fixtures
