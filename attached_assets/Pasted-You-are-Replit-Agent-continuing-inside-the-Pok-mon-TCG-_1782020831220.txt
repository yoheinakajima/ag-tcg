PART F — Promotion Gate v1 design doc
Write docs/PROMOTION_GATE_V1.md.

Promotion Gate v1 answers:
When does a probation candidate become active, family_champion, retired, or stay probation?

Define statuses and actions:
- stay_probation
- activate
- promote_family_champion
- retire_to_retired
- quarantine
- insufficient_evidence
- blocked_protected_status
- blocked_invalidity
- blocked_public_reference

Strict conservative rules:
A probation candidate may become active only if:
1. It has enough total games: default >= 40.
2. It has enough anchor games: default >= 10.
3. It has direct parent/family comparison where possible.
4. Wilson lower bound clears parent/family baseline by a margin.
5. No validity collapse: invalid/error/timeout rate below threshold.
6. No benchmark collapse against public references if benchmark evidence exists, but public references are diagnostic only.
7. Non-inertness or meaningful deck-composition delta is proven.
8. It does not regress badly against live controls / water controls.
9. Self-mirror/noise-floor caveat is respected when doing direct H2H.
10. No protected candidate is demoted.

Family champion promotion requires stricter criteria:
- enough games vs family peers and anchors,
- current family champion baseline exists,
- lower confidence bound clears champion baseline by margin,
- no collapse against control/benchmark families.

Retirement/quarantine:
- retire only after enough evidence and only if not protected.
- quarantine only for repeated hard validity failures.
- never delete tarballs.
