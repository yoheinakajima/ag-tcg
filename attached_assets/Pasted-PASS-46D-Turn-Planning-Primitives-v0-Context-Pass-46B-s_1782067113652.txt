PASS 46D — Turn-Planning Primitives v0

Context:
Pass 46B showed the public-reference gap is behavioral / turn-planning, not deck-list-only. Pass 46C built a local, frame-persisting diagnostic lane with full env.steps decision-frame traces. Production is still soaking the Pass-42 probation candidates and must remain untouched. This pass should build reusable turn-planning primitives from the trace data, not optimize a single deck and not generate candidates.

Hard scope:
- LOCAL / READ-ONLY / INFRASTRUCTURE ONLY.
- Do not mutate production Object Storage.
- Do not run a production tick.
- Do not change root main.py or deck.csv.
- Do not generate candidates.
- Do not promote, retire, quarantine, queue, upload, submit, republish, or change lifecycle status.
- Do not optimize a single deck.
- Do not copy or port public-reference policy logic.
- Public references remain benchmark-only opponents, never candidates, parents, sources, or promotion targets.
- Keep unsupported claims explicit: no exact damage, lethal, missed-KO, Boss/gust correctness, spread-placement correctness, or best-action claims unless backed by cg Search API. Numeric attackId alone is insufficient.
- Start application must remain not-started; it is the frozen Kaggle entrypoint.

Objective:
Build reusable, tested turn-planning primitives that future candidate-generation passes can call. These primitives should operate on persisted decision frames from Pass 46C and raw/cg-typed observations where available. They should be conservative, never-raise, and honest about unsupported information.
